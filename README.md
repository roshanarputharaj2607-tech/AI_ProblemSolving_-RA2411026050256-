Tic Tac Toe — Project Description
Tic Tac Toe (also called Noughts & Crosses) is a classic two-player strategy game played on a 3×3 grid. It's one of the most iconic games in the world and a go-to project for developers learning game logic.

🎮 How It Works
Players take turns marking a cell with their symbol — X or O. The first player to get 3 in a row (horizontally, vertically, or diagonally) wins. If all 9 cells are filled with no winner, it's a draw.

🛠️ What's Built in This Project
Game Modes

2 Player — two people play on the same screen, taking turns
vs CPU — play against an AI powered by the Minimax algorithm, which plays perfectly and never loses

Features

Turn indicator showing whose move it is
Win detection with highlight on the winning combo
Draw detection when the board is full
Score tracking across multiple rounds for X, O, and draws
New Game and Reset Scores buttons


🧠 The Minimax Algorithm
The CPU opponent uses Minimax, a classic AI decision-making algorithm used in game theory. It works by simulating every possible future move and picking the one with the best outcome. This makes the CPU unbeatable — the best you can do against it is a draw.
